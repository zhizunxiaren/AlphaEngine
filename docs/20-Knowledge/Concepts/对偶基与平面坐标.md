# 对偶基与平面坐标

> [!abstract] 一句话结论
> 对偶基 `u*`、`v*` 不是「另一组方向」，而是**读坐标的尺子**：`P·u* = α`、`P·v* = β`。`u*` 由两条约束唯一钉死——**和 u 点乘得 1，和 v 点乘得 0**。这两条同时管了方向（垂直谁）和刻度（除以谁）。

> [!important] 定义卡
> 给定基 `u, v`，其对偶基 `u*, v*` 是满足下式的唯一一对向量：
>
> ```
> u*·u = 1      u*·v = 0
> v*·u = 0      v*·v = 1
> ```
>
> 即 `u*_i · u_j = δ_ij`（本位为一、交叉为零）。四条约束、两个未知向量，恰好唯一可解——前提是 `u` 与 `v` 不共线。

演示页（4 个动画场景，可拖拽）：[平面坐标与对偶基](../../demos/plane-coords/index.html)。

## 0. 前因：一个点怎么在斜基下读出坐标

这套东西不是为了「高级」才出现的，它解决一个很具体的问题。

平面上的点有两种描述方式，二者互相独立：

| 描述方式 | 表达式 | 谁来定 |
|---|---|---|
| **点集式**：满足方程的点构成平面 | `n·X = D`，即 `A·x + B·y + C·z = D` | 法向量 `n = (A,B,C)` 与常数 `D` |
| **参数式**：由基点加两个方向张成 | `P = Q + α·u + β·v` | 基点 `Q`、基向量 `u`、`v` |

第一种回答「哪些点在这个平面上」，第二种回答「平面上的某个点落在第几格」。工程里两者都要：求交用点集式（代射线进去解 `t`），取纹理坐标 / 反解 UV / 求重心坐标用参数式（要的是 `(α, β)`）。

> [!note] 顺带：为什么系数 `(A, B, C)` 就是法向量
> 在平面上任取两点 `P₁`、`P₂`，两者都满足方程，相减得
> ```
> A(P₁x − P₂x) + B(P₁y − P₂y) + C(P₁z − P₂z) = 0
> ```
> 左边正是 `(A,B,C) · (P₁ − P₂)`。而 `P₁ − P₂` 是平面内**任意**一个方向向量。一个向量和平面内所有方向都垂直，它只能垂直于这个平面——所以 `(A,B,C)` 是法向量。常数项只是把平面平移：`D = n·Q`，即「法向在基点上的读数」。

**现在的问题**：已知 `Q`、`u`、`v`、`P`，求 `α`、`β`。

**朴素想法**是投影：`α' = (P·u) / (u·u)`。这在 `u ⊥ v` 时完全正确，`u` 与 `v` 一歪就错。误差有解析式（§5.3），不是数值噪声——它是系统性的、可预测的偏移。

所以需要一个**只对 `u` 敏感、对 `v` 完全瞎**的探针。这个探针就是 `u*`。

## 1. 把问题写成方程

`P − Q = α·u + β·v` 拆成分量，二维下是两个方程、两个未知数：

```
u_x·α + v_x·β = d_x
u_y·α + v_y·β = d_y
```

其中 `d = P − Q`（为省事，下面令 `Q = 0`，则 `d = P`；有基点时把 `P` 换成 `P − Q` 即可）。

矩阵形式：

```
B · [α, β]ᵀ = d ,     B = [ u  v ] = [ u_x  v_x ]
                                          [ u_y  v_y ]
```

**`B` 的列是基向量**。这一点很关键：`B` 把「格子坐标」映射成「空间位置」，`B⁻¹` 才是把位置读回格子坐标的那台机器。

## 2. Cramer 法则解出

记

```
det = u_x·v_y − u_y·v_x  =  u × v      （二维叉积，取 z 分量，是标量）
```

Cramer 法则给出

```
α = ( d_x·v_y − d_y·v_x ) / det
β = ( u_x·d_y − u_y·d_x ) / det
```

到这一步已经能算了。但它把 `α` 写成了 `d` 的**两个分量与 `v` 的两个分量交叉相乘**——看不出几何含义，而且每换一个 `P` 都要重算一遍。

## 3. 关键一步：把分子改写成一个点积

看 `α` 的分子：

```
d_x·v_y − d_y·v_x  =  (d_x, d_y) · (v_y, −v_x)  =  d · (v_y, −v_x)
```

验算：`d·(v_y, −v_x) = d_x·v_y + d_y·(−v_x)`，与分子逐项相同。

于是

```
α = d · [ (v_y, −v_x) / det ]
```

方括号里那一坨**只和基有关，和 `P` 无关**。给它起个名字：

```
u* = ( v_y, −v_x ) / det
v* = ( −u_y, u_x ) / det
```

就得到

```
α = P · u*          β = P · v*
```

> [!tip] 这一步做了什么
> 把一个「解方程组」的问题，变成了「两次点积」。方程组每来一个 `P` 都要解一次；点积只需要基算一次，之后每个点两次乘加。
>
> 这不是数学游戏，是 §7 里所有工程优化的来源。

注意符号：`u*` 的分量是 `v` 的分量**旋转 90° 再除以 det**；`v*` 是 `u` 的分量**反方向旋转 90° 再除以 det**。两个旋转方向相反，这样才能保证 `u*·u = +1` 而不是 `−1`。

## 4. 验证：两个性质分别管方向与刻度

把定义代进去，四条约束全部自动成立：

```
u*·u = (v_y·u_x − v_x·u_y) / det = det / det = 1     ✓
u*·v = (v_y·v_x − v_x·v_y) / det = 0 / det = 0        ✓
v*·v = (−u_y·v_x + u_x·v_y) / det = det / det = 1     ✓
v*·u = (−u_y·u_x + u_x·u_y) / det = 0                 ✓
```

四条一起看，就是矩阵乘法：

```
[ u*_x  u*_y ] [ u_x  v_x ]   [ 1  0 ]
[ v*_x  v*_y ] [ u_y  v_y ] = [ 0  1 ]
```

即 `B⁻¹ · B = I`。**所以 `u*`、`v*` 就是 `B⁻¹` 的两行**——「对偶基」不是新发明的对象，它是逆矩阵按行读出来的结果。

分工很干净：

| 分子 | 分母 | 分管什么 |
|---|---|---|
| `(v_y, −v_x)` | — | **方向**：垂直于 `v`（因为它是 `v` 旋转 90°），所以沿 `v` 走时读数不变 |
| — | `det` | **刻度**：把点积缩放到「过 `u` 处读数恰为 1」 |

只有方向没有刻度，`u*·u` 会是某个非 1 的数，读出来的是「缩放过」的格数；只有刻度没有方向，沿 `v` 走也会改变 `α`。两条缺一不可。

## 5. 尺子的三种读法

### 5.1 长度：`|u*| = 1 / h_u`

`u*` 垂直于 `v`，所以它的模长等于「`u` 在 `v` 法向上的投影」的倒数：

```
h_u = |u| · sinθ = |u × v| / |v|        （u 到 v 所在直线的垂直距离，也是两条 α 格线之间的垂直间距）

|u*| = 1 / h_u
```

含义：**格子越扁（`u` 越贴着 `v`），`h_u` 越小，`u*` 越长**。尺子被拉长，是因为同样的空间位移对应的格数变化变小了——要放大读数倍率才能读准。

### 5.2 梯度：`u* = ∇α`

`α(P) = P·u*` 是 `P` 的线性函数，它对 `P` 的梯度就是 `u*` 本身：

```
∇α = u*        ∇β = v*
```

这一条把前面所有比喻都收拢了：`u*` 是 `α` **增长最快的方向**，它的模长是**每单位距离涨几格**；反过来 `1/|u*| = h_u` 就是**涨一格要走多远**。「尺子」不是比喻，是梯度的物理含义。三维里同理：`∇α` 垂直于 `β`、`γ` 的等值面。

### 5.3 「格数不是距离」

| 动作 | `Δα` | `Δβ` | 说明 |
|---|---|---|---|
| 沿 `u` 走一格（`‖u‖`） | **+1** | 0 | 跨过一条 α 格线，落点是 `P + u` |
| 沿 `v` 走一格（`‖v‖`） | 0 | **+1** | 沿 α 格线滑行，α 一格都没变 |
| 垂直跨过一条 α 格线 | +1 | 0 | 这段距离是 `h_u = 1/‖u*‖`，**不等于** `‖u‖` |
| 斜着跨 | +1 | 变了 | α 只记「跨了几条线」，不记斜着走了多远 |

所以 `α = 2.5` 的含义是「在 α=2 与 α=3 之间、正中间」，而不是「离原点 2.5 米」。**格数是坐标，不是长度。** 想把格数换成距离，要乘 `h_u`；想把距离换成格数，要除以 `h_u`——这一步就是乘 `|u*|`。

投影误差也用这套语言写出来：

```
α' = (P·u)/(u·u) = α + β·(u·v)/|u|²
```

误差项 `β·(u·v)/|u|²` 就是「`β` 那一部分漏进了 `α` 的读数」。`u ⊥ v` 时 `u·v = 0`，误差归零——这就是正交基下投影法好用的原因。

## 6. 推广：三维与逆矩阵语言

三维下基为 `u, v, w`，令

```
det = u · (v × w)        （平行六面体体积，带符号）
```

则

```
u* = (v × w) / det
v* = (w × u) / det
w* = (u × v) / det
```

即「**另外两根的叉积 ÷ 体积**」。`v × w` 垂直于 `v`、`w` 张成的平面（于是与它们点乘为 0），除以 `det` 后与 `u` 点乘恰好为 1。三维下 `u*` 就是「对面那片平行四边形的法向，按体积归一」。

> [!note] 二维公式是三维的特例
> 把平面法向按 `1/|n|²` 缩放后当作第三根基向量：`w = n / |n|²`，`n = u × v`。代入三维公式得 `det = u·(v × n)/|n|² = |n|²/|n|² = 1`，于是 `u* = (v × n)/|n|²`，与二维的 `(v_y, −v_x)/det` 完全一致（二维叉积就是 `n` 的 z 分量）。平面内的问题不必引入第三维，但两套公式不是两个东西。

矩阵语言一句话：**`B⁻¹` 的行 = 对偶基**（`B` 的列 = 原基）。正交时 `B⁻¹ = Bᵀ`，对偶基退化成基向量本身——这是「正交基特别好用」的真正原因，也是「对偶基就是自己」这个错觉的来源。

## 7. 用在哪：四个真实落点与算例

**核心动机**：基在一段几何上固定，点在变。三角形、四边形、平面的 `(u, v)` 在一个图元内是常量，而 `P` 逐像素、逐采样点变化。预存 `u*`、`v*`（或 `B⁻¹`）就把它从「每点解 2×2 方程组」降为「每点两次点积」，且**无分支、无除法**（除法已经挪到预计算里）。

### 7.1 命中四边形 → 纹理坐标（本仓库 `Engine/quad.h`）

这是最近的落点。`Engine/quad.h` 的 `quad::hit()` 已按「先解 `t`、再读 `(α, β)`」的两步结构实现（截至 2026-10-28 核对）：构造期预存 `n`、`D` 与 `w = n/(n·n)`，命中后把读到的 `(α, β)` 交给 `hit_ab()` 判内部并写入 `rec.u / rec.v`。下面给的是这段换算的来历、它的另一种写法，以及两种写法的取舍。

> [!note] 两步结构本身不在本页
> 「为什么必须先解 `t` 再判内部」——即等式与不等式的分工、以及丢掉边界信息后 `t` 的含义——记在
> [[20-Knowledge/Concepts/射线与几何体求交#2. 射线与平面、有限四边形求交|射线与几何体求交 · §2]]。本页只管「第二步怎么读坐标」。

`quad` 用 `Q + u + v` 定义对角点，说明 `u`、`v` 携带长度、代表**整条边**，参数域恰好是单位正方形。于是读出来的 `α、β ∈ [0,1]` **就是 UV，不用再归一化**——这是很多人白写一次除法的原因。

这个落点需要的东西，用符号写清楚是四个量：

```
n      = u × v
inv    = 1 / (n·n)                // = 1/det²，det 是平面内的二维叉积（见 §6 note）
u_star = (v × n) · inv            // 垂直于 v，与 u 点积为 1
v_star = (n × u) · inv            // 垂直于 u，与 v 点积为 1

α = (P − Q) · u_star
β = (P − Q) · v_star
```

`n`、`inv`、`u*`、`v*` 只依赖 `(u, v)`，在一个四边形内是常量，与该图元的生命周期同长；`α`、`β` 依赖 `P`，每个命中点各算一次。这个分工决定了哪些量该在什么时候算——具体放在构造函数、`hit()` 还是别处，由实现者决定。

**算例**（斜基，不正交才看得出区别）。取

```
Q = (0,0,0)   u = (2,0,0)   v = (1,0,2)        // 同处 y=0 平面
```

```
n      = u × v      = (0, −4, 0)
|n|²   = 16                ⇒ inv = 0.0625
u*     = (v × n)/16 = (8, 0, −4)/16 = ( 0.5, 0, −0.25)
v*     = (n × u)/16 = (0, 0,  8)/16 = ( 0,   0,  0.5 )
```

自检：`u*·u = 0.5·2 = 1`、`u*·v = 0.5·1 + (−0.25)·2 = 0`。✓

现在取一个点 `P = 1.5u + 0.8v = (3.8, 0, 1.6)`（先藏在心里，待会儿看能不能读回来）：

```
α = P·u* = 3.8·0.5 + 1.6·(−0.25) = 1.9 − 0.4 = 1.5   ✓
β = P·v* = 1.6·0.5               = 0.8               ✓
```

**对照投影法**：`α' = (P·u)/(u·u) = 7.6/4 = 1.9`，比真值 1.5 多 0.4——正好等于 `β·(u·v)/|u|² = 0.8·2/4 = 0.4`。这个 0.4 不是舍入误差，是**几何错误**：UV 会整体错位，检查时表现为「纹理像被斜着拖了一下」。

**正交特例**：若 `u = (2,0,0)`、`v = (0,0,2)`，则 `u* = (0.5,0,0) = u/|u|²`、`v* = (0,0,0.5) = v/|v|²`。对偶基退化成「除以边长的平方」——这就是为什么正交平面上直接用投影也看不出错。

**另一种写法：叉积形式（与本节的 `u*`、`v*` 等价）**

上面预存两个对偶向量。RTIOW 系列在 `quad::hit()` 里用的是另一种形式：构造期只存一个 `w = n/(n·n)`，每次命中做两次叉积。

```
n   = u × v
w   = n / (n·n)                       // 只依赖基，构造期算一次
α = dot(w, cross(p, v))               // p = 命中点 − Q
β = dot(w, cross(u, p))
```

它与 `α = p·u*`、`β = p·v*` 是同一个数，差别只在**三重积轮换**（`n·(p×v) = p·(v×n)`）：

```
w·(p×v) = n·(p×v)/(n·n) = p·(v×n)/(n·n) = p·u*
w·(u×p) = n·(u×p)/(n·n) = p·(n×u)/(n·n) = p·v*
```

推导来自叉积消元，与 §6 的三维公式同源：`p×v = (αu + βv)×v = α·n + β·(v×v) = α·n`，沿 `n` 读一次即得 `α`；`u×p = β·n` 同理。几何含义是**带符号面积比**：

```
α = 面积(p, v) / 面积(u, v)           // Cramer 法则：把基里 u 那一列换成 p
β = 面积(u, p) / 面积(u, v)
```

所以 `p` 里沿 `v` 的那部分（`βv`）完全不影响 `α`——因为 `v×v = 0`，它在叉积里自己消失了。这也解释了为什么 `α` 是「跨了几条 α 格线」而不是「沿 `u` 走了多远」（§5.3）。

两种写法的取舍：

| | 预存 `w`（叉积形式） | 预存 `u*`、`v*`（对偶基形式） |
|---|---|---|
| 构造期算什么 | 1 个向量 `w` | 2 个向量 `u*`、`v*` |
| 每次命中 | 2 次叉积 + 2 次点积（约 18 次乘法） | 2 次点积（约 6 次乘法） |
| 读法 | 面积比 | 尺子读数 |

数学等价，选择是「内存 vs 每次命中算量」的取舍。**同一段代码里不要两种混用**——一旦混用，`α`、`β` 的符号约定容易在改写时错开，而症状只是 UV 翻转，不会报错。

三个只在这个形式下容易写错的点：

1. **叉积顺序**：必须是 `cross(p, v)` 与 `cross(u, p)`。写成 `cross(v, p)` / `cross(p, u)` 整体差一个负号。
2. **分母是 `n·n` 不是 `|n|`**：`w` 的量纲是 `L⁻²`，乘上 `L²` 的叉积才约成无量纲的面积比。写成 `n/|n|` 时 `α` 会带一个 `|n|` 因子，只在 `|n| = 1` 时碰巧对。
3. **`α`、`β` 就是 UV，不要再归一化**：`u`、`v` 是整条边，参数域已是单位正方形。需要额外折算的是例外情况（例如基取半轴、参数域变成 `[-1,1]` 的椭圆与圆环，此时要 `a/2 + 0.5` 折回 `[0,1]`）。

### 7.2 三角形重心坐标：以某个顶点为基点、两条边为基

重心坐标是同一个公式换个基点。以 `B` 为原点，两条边 `e0 = A−B`、`e1 = C−B` 为基，则 `P − B = w_A·e0 + w_C·e1`，读 `(w_A, w_C)` 就是对偶基，`w_B = 1 − w_A − w_C`。

**算例**：`A(0,0)`、`B(4,0)`、`C(0,4)`、`P(1,2)`。

```
e0 = A−B = (−4, 0)      e1 = C−B = (−4, 4)      d = P−B = (−3, 2)
det = e0 × e1 = (−4)(4) − (0)(−4) = −16

e0* = ( e1_y, −e1_x)/det = ( 4,  4)/(−16) = (−0.25, −0.25)
e1* = (−e0_y,  e0_x)/det = ( 0, −4)/(−16) = ( 0,     0.25)

w_A = d·e0* = (−3)(−0.25) + 2(−0.25) = 0.75 − 0.5 = 0.25
w_C = d·e1* = 2·0.25                 = 0.5
w_B = 1 − 0.25 − 0.5                 = 0.25
```

用面积比独立验算：`[ABC] = 8`，`[PBC] = 2` ⇒ `w_A = 0.25`；`[PAB] = 4` ⇒ `w_C = 0.5`。✓ 两者必须一致——重心坐标的定义就是面积比，对偶基只是它的解析形式。

**与边函数的关系**（光栅化器里的那个写法）：

```
E_AB(P) = (P−A) × (B−A)
w_C = E_AB(P) / E_AB(C)
```

代入算一遍：`E_AB(P) = (1,2)×(4,0) = −8`，`E_AB(C) = (0,4)×(4,0) = −16`，比值 `0.5 = w_C` ✓。所以边函数不是另一套东西，它是「分母提到外面」的重心坐标；判「点在哪一侧」就是判读数符号。硬件光栅化器用的正是这个，只是把 `1/E_AB(C)` 和 `E_AB(P)` 都乘上 2 倍面积以便整数运算。

### 7.3 光线与平面求交：分母 `n·D` 就是一次读数

```
t = n·(Q − O) / (n·D)
```

`n·D` 是射线方向在法向对偶基上的读数——`|n·D|` 小，说明射线几乎平行于平面，`t` 会爆掉。

**算例**：`Q = (0,0,0)`、`n = (0,1,0)`（即平面 `y = 0`）、`O = (0,5,0)`、`D = (0,−1,1)`（不必归一化）。

```
n·(Q−O) = (0,1,0)·(0,−5,0) = −5
n·D     = (0,1,0)·(0,−1,1) = −1
t = (−5)/(−1) = 5

命中点 = O + 5D = (0, 5, 0) + (0, −5, 5) = (0, 0, 5)     ✓ 落在 y=0 上
```

拿到命中点后再用 §7.1 的两行读 `α、β` 判断「在不在四边形内」（`0 ≤ α,β ≤ 1`）。**顺序很重要**：先解 `t`（一维，便宜），再读 `α、β`（两次点积），不要一上来就解二维方程组。

> `t` 的量纲跟着 `D` 走：`D` 归一化时 `t` 是真实距离；未归一化时 `t` 以 `|D|` 为单位。求交判据 `|n·D| < eps·|n||D|` 等价于 `|cos∠(n,D)| < eps`，是无量纲的——和 §7.5 同一个道理。

### 7.4 纹理 mip 与各向异性：UV 的屏幕导数就是 `u*`

`α` 对 `P` 的梯度是 `u*`（§5.2），所以屏幕上走 1 像素带来的 UV 变化量，就是把那一像素的位移向量点乘 `u*`：

```
du/px = (dP/dx) · u*        dv/px = (dP/dx) · v*
du/py = (dP/dy) · u*        dv/py = (dP/dy) · v*
```

**算例**：1024×1024 纹理，实测每像素 UV 变化 `0.01`。

```
每像素跨过的 texel 数 = 0.01 × 1024 = 10.24
LOD = log2(10.24) ≈ 3.36                → 在 mip 3 与 4 之间做三线性
```

如果 `u` 方向是 `0.01`、`v` 方向是 `0.001`（长宽比 10:1），只取 `max` 会让短边方向过度模糊——这是各向异性过滤存在的原因，也是斜视地面时「远处糊成一片、近处还在闪」的根源。

**工程含义**：`u*`、`v*` 在两个地方被复用——反解 UV，和算 UV 的屏幕导数。这也是为什么它们值得预存，而不是每次现算。

### 7.5 退化：`nan` 和「整面糊成一色」都是从这里来的

`|u × v| = |u|·|v|·sinθ`，所以判据要除回去，变成无量纲的 `sin²θ`：

```
好：|n|² > eps · (|u|² · |v|²)        // 实际在比 sin²θ
坏：|n|  > 1e-6                        // 基长 1e-3 时全部误判为退化
```

**算例**：`u = (1,0)`、`v = (1, 1e-4)`，`sin²θ ≈ 1e-8`。

```
|u*| = 1/h_u = 1/|u|sinθ ≈ 1/1e-4 = 1e4
```

于是命中点坐标里 `1e-4` 量级的误差，被放大成 UV 上的 `1` 格偏差；`du/px` 跟着虚高，LOD 直接跳最高层，整块面塌成平均色。**画面症状是「这个面糊了」，不是报错**——所以退化必须在基被使用之前挡住，而不是等到除出 `inf` 再看：

```
拒绝条件： (n·n) ≤ eps · (u·u) · (v·v)        // 等价于 sin²θ ≤ eps
```

三维版用 `det² > eps·|u|²|v|²|w|²`。`eps` 的取值依赖坐标量级与浮点宽度（float 约 `1e-12`~`1e-10`，double 可到 `1e-20`），本仓库尚无实测标定，见 §12。

### 7.6 不该套用的三处

对偶基不是万用扳手，误用的成本是「公式对、结果错」：

| 场景 | 为什么不能用 | 正确做法 |
|---|---|---|
| 球体 UV | 球面参数化是角度，不是斜基线性坐标 | `atan2(−z, x) + π`、`acos(−y)`（本仓库 `Engine/sphere.h:82-86` 即此） |
| 透视校正插值 | 屏幕空间的 `(α, β)` 经投影后**不是**线性函数 | 先插 `α/w`、`β/w`、`1/w`，最后再除（光栅化页 §7） |
| AABB / BVH 划分 | 只用坐标轴分量，没有斜基 | 直接比较 `min/max` 分量 |

### 7.7 总表

| 落点 | 输入 | 用的形式 | 省掉什么 | 不用的后果 |
|---|---|---|---|---|
| 四边形 UV（`quad.h`） | `Q, u, v, P` | `α = (P−Q)·u*` | 每点解 2×2 方程组 | UV 斜向错位（§7.1 的 0.4） |
| 三角形重心坐标 | 三顶点、`P` | 以顶点为基的对偶基 | 三次面积计算 | 与边函数重复实现两套，易不一致 |
| 平面求交 | `n, Q, O, D` | `t = n·(Q−O)/(n·D)` | 展开平面方程 | 平行判定写成绝对值比较，量纲错 |
| mip / 各向异性 | `u*, v*`、屏幕位移 | `du/px = dP/dx·u*` | 差分近似或解析重复求导 | LOD 跳变、远处闪烁 |
| 退化防护 | `u, v` | `sin²θ` 判据 | 试除后判 `isfinite`（太晚） | `nan` 或整面糊色 |

## 8. 例子走完全程

取 `u = (2, 0)`、`v = (1, 1)`、`P = (5, 3)`。

**① 行列式**

```
det = u_x·v_y − u_y·v_x = 2·1 − 0·1 = 2
```

**② 对偶基**

```
u* = ( v_y, −v_x ) / det = ( 1, −1 ) / 2 = ( 0.5, −0.5 )
v* = ( −u_y, u_x ) / det = ( 0,  2 ) / 2 = ( 0,    1   )
```

**③ 读坐标**

```
α = P·u* = 5·0.5 + 3·(−0.5) = 2.5 − 1.5 = 1
β = P·v* = 5·0   + 3·1      = 3
```

**④ 回代验证**

```
α·u + β·v = 1·(2,0) + 3·(1,1) = (2,0) + (3,3) = (5,3) = P   ✓
```

**⑤ 对照投影法错在哪**

```
α' = (P·u)/(u·u) = (10 + 0)/4 = 2.5            （错，真值 1）
误差 = β·(u·v)/|u|² = 3·2/4 = 1.5              （2.5 = 1 + 1.5，与解析式吻合）
```

**⑥ 尺子长度**

```
|u*| = √(0.25 + 0.25) = 0.7071
h_u  = |u × v| / |v| = 2 / 1.4142 = 1.4142
1/h_u = 0.7071                                  ✓ 与 |u*| 一致
```

即：α 涨一格，垂直距离要走 `1.4142`；反过来走单位距离，α 涨 `0.7071` 格。

## 9. 五个常见误解

| 误解 | 事实 |
|---|---|
| 「对偶基就是互相垂直」 | `u* ⊥ v`、`v* ⊥ u`（**交叉**垂直），但 `u*` 与 `v*` 之间一般**不**垂直。见例：`u*=(0.5,−0.5)`、`v*=(0,1)`，点积 `−0.5 ≠ 0` |
| 「对偶基是逐元素取倒数 `(1/u_x, 1/u_y)`」 | 只在轴对齐时偶然成立。反例 `u=(2,1)`、`v=(1,3)`：正确 `u*=(0.6,−0.2)`；`(0.5,1)` 既不垂直 `v`，点积也不为 1 |
| 「`x·x* + y·y* + z·z* = 1`」 | 错。每条单独是 `e_i·e*_i = 1`，三项相加是 3（`n` 维就是 `n`，没有信息量）。真正的整体恒等式是**外积和**：`Σ e_i ⊗ e*_i = I` |
| 「`u·u* = 1` 就确定了 `u*`」 | 一条方程定不了二维向量，还需要 `u*·v = 0`。`u·u* = 1` 只钉住「在 `u` 方向上的分量」，另一维自由 |
| 「对偶基只在图形学里出现」 | 它就是线性代数里的**对偶空间基**。`u*` 本是一个线性泛函 `P ↦ α`，借助内积把它表示成一个向量（Riesz 表示），才得到这里的公式。名字里的「对偶」不是修辞 |

## 10. 四个等价视角（同一件事）

| 视角 | 表述 |
|---|---|
| 约束 | 四条点积：本位为一、交叉为零（定义卡） |
| 几何 | 垂直于「另一根」，且与「自己那根」点积为 1（交叉垂直 + 刻度） |
| 代数 | `B⁻¹` 的两行；正交时退化为 `Bᵀ = B` |
| 分析 | `α(P)` 的梯度：`∇α = u*`；长度 `1/h_u`，方向是 α 增长最快处 |
| 三维 | `u* = (v × w) / (u·(v×w))`：对面平行四边形的法向 ÷ 平行六面体体积 |

## 12. 待核验与延伸

- 本页只讨论**仿射**基与线性坐标。透视投影下的插值不是线性的（要除以 `w`），那属于光栅化页 §7 的透视校正插值，不能直接套 `α = P·u*`。
- 双线性/三线性参数化（四边形、四面体）不是线性基，没有这种「一组对偶基读全部坐标」的简洁形式，需要按单元分别解。
- 非正交基上的对偶基与**协变/逆变分量**是同一件事的两种语言（`α` 是逆变分量，`u*` 是余切基）。若后续要用张量记号描述曲面参数化，应先在此登记映射关系，避免两套记号各写一份。
- 退化判据里的 `eps` 尚无实测标定值：等 `Engine/` 侧有实际求交代码与量级后回填。
