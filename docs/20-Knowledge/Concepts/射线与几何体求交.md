## 1. 射线与球体求交

### 1.1 推导

**射线**由起点与方向参数化：

```
P(t) = O + t·D              t ∈ [0, ∞)
```

**球面**是到球心距离等于半径的点集：

```
|X - C|² = r²
```

把 `P(t)` 代入并展开。令 `oc = C - O`（由射线起点指向球心的向量）：

```
|t·D - oc|² = r²
t²(D·D) - 2t(D·oc) + (oc·oc - r²) = 0
```

这是关于 `t` 的一元二次方程，三个系数各对应一个几何量：

| 系数 | 表达式 | 含义 |
|---|---|---|
| `a` | `D·D` | 方向向量的**平方长度**（未归一化时不为 1） |
| `h` | `D·oc` | 方向与「起点 → 球心」的投影（**半 b 形式**，标准式里 `b = -2h`） |
| `c` | `oc·oc - r²` | `c < 0` 当且仅当**起点位于球内部** |

> **半 b 形式**：标准求根公式 `t = [-b ± √(b²-4ac)] / 2a` 代入 `b = -2h` 后可整体约掉因子 2，得到 `t = [h ± √(h²-ac)] / a`。系数与判别式都少一次乘法，是图形学中的标准写法。

**判别式** `Δ = h² - a·c`，**两根**：

```
t = (h ± √Δ) / a
```

| 判别式 | 几何含义 |
|---|---|
| `Δ < 0` | 射线与球**不相交** |
| `Δ = 0` | 射线与球**相切**（重根） |
| `Δ > 0` | **两个交点**——穿入点与穿出点 |

### 1.2 两条根的含义

因为 `a > 0`，所以 `(h - √Δ)/a ≤ (h + √Δ)/a`：

```
        相机
         ●────────────→        ┌───────────┐
                  t₁ ↗         │    球      │  ↘ t₂
                               └───────────┘
      t₁ = (h - √Δ)/a  ← 近根，穿入点
      t₂ = (h + √Δ)/a  ← 远根，穿出点
```

渲染时应当取**近根**——光线先撞到的那一面。但有两种情形需要回退到远根或直接排除：

| 情形 | 条件 | 结果 |
|---|---|---|
| 起点在球外、球在前方 | `c > 0` 且 `h > 0` | 两根皆正，取近根 |
| 球在相机背后 | `c > 0` 且 `h < 0` | 两根皆负，未命中 |
| **起点在球内部** | `c < 0` | 近根为负、远根为正，**必须取远根** |
| 起点在球面上 | `c = 0` | 一根为 0，一根为正 |

> `c < 0` 等价于 `|C - O| < r`，即相机落在球体内——这是"相机可以进入几何体"这类场景（例如体积、开放场景漫游）必须支持的路径。

### 1.3 根的范围筛选

求交不能只看"有没有解"，还要看解是否落在**允许的参数范围**内。有效范围是**开区间**：

```
t_min < t < t_max
```

筛选逻辑是"**先近后远，都不行才算未命中**"：

```
root ← (h - √Δ) / a
if root 不在 (t_min, t_max):
    root ← (h + √Δ) / a
    if root 也不在 (t_min, t_max):
        未命中
```

用比较运算表达"不在范围内"（即对 `t_min < t < t_max` 取反）：

```
root <= t_min  ||  root >= t_max
```

`t_min` 与 `t_max` 各有明确用途：

- **`t_min`** —— 剔除自交。次级光线（阴影、反射、折射）从表面出发，必须跳过 `t ≈ 0` 处与自身表面的伪交
- **`t_max`** —— 限制搜索深度。任何更远的交点已经不可能是最近的表面

### 1.4 法线与朝向

**外法线**由「交点 − 球心」归一化得到：

```
N = (P - C) / r
```

交点在球面上，所以 `|P - C| = r`，除以 `r` 恰好归一化，无需再调 `unit_vector`。

**朝向必须规范化。** 外法线总是朝球外，但光线的来向不一定：

| 情形 | `dot(D, N)` | 处理 |
|---|---|---|
| 光线从外部射入 | `< 0` | 法线与光线反向，**保持不变** |
| 光线从内部射出 | `> 0` | 法线与光线同向，**翻转为 `-N`** |

同时记录一个 `front_face` 布尔量，供后续材质判断"看到的是正面还是背面"。**若只赋外法线而不做翻转，从几何体内部观察到的着色会整体反相。**

### 1.5 边界与陷阱

- **区间是开的。** 有效判据是 `t_min < t < t_max`；写成 `t_min <= t <= t_max` 会改变边界语义，导致贴面自交或边界处重复命中。
- **比较方向易写反。** 判据里是 `root >= t_max` 而不是 `root <= t_max`。写成 `<=` 时该子条件恒为真，使"不在范围内"永远成立——表现为**几何体完全无法被渲染**。若 `t_max` 取无穷大，这种错误尤其隐蔽：它不会报错，只是画面里什么都没有。
- **方向向量未归一化时 `t` 不是距离。** 射线方向若由"像素位置 − 相机位置"直接给出，则 `a = |D|² ≠ 1`，`t` 只是参数不是欧氏距离。这不影响解的正确性（`t` 仅用于排序与求点），但会影响 `t_min` / `t_max` 的取值直觉——按距离设定的阈值会随像素位置漂移。
- **零半径会污染法线。** 半径若被钳制为 0，`(P - C) / r` 会除零得到 NaN。应在求交入口直接拒绝非正半径，而不是让 NaN 扩散到着色阶段。
- **哨兵返回值表达力不足。** 用 `-1` 表示"未命中"，无法区分"未命中"与"命中但参数为负"，调用方还必须记住这条约定。正解是返回 `bool`，命中信息经输出参数带回。
- **相切附近对精度敏感。** `Δ ≈ 0` 时浮点误差会让"擦过"变成"未命中"或产生极小 `a`。远距离物体的表面可能出现噪点或漏缝。

### 1.6 在渲染器中的落点

| 场景 | 做法 |
|---|---|
| 求交接口 | 返回 `bool`，命中信息（`t`、交点、法线、`front_face`）经输出参数带回，而非哨兵返回值 |
| 允许穿入几何体 | 必须实现"近根不在范围内则回退远根"的路径 |
| 法线朝向 | 强制法线与光线反向并记录 `front_face`，供材质区分正反面 |
| 自交剔除 | 次级光线用 `t_min > 0` 跳过出发面 |
| `t` 的语义 | 若方向未归一化，`t_min` / `t_max` 不能按物理距离设定 |

> 后续发展方向：单个求交函数会被 `hittable` 抽象取代——虚接口返回 `bool` 并填充 `hit_record`，再由 `hittable_list` 组合出任意场景。本页只记录数学，接口设计在形成体系后另立章节。
