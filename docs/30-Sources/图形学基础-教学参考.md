# 图形学基础教学参考

- 采集日期：2026-10-21；2026-10-28 追加同系列 *The Next Week* 的 `quad` 一节（见下表末行）。
- 类型：同一教学问题域的参考集合，不是对单本书的逐章翻译。
- 下游：[[20-Knowledge/Concepts/图形学基础与渲染流程]] 与 [[20-Knowledge/Tooling/教学演示页]]。

| 一手来源 | 本次核对范围 | 适用边界与许可 |
|---|---|---|
| [PBRT 4 · Geometry and Transformations](https://pbr-book.org/4ed/Geometry_and_Transformations) | 点、向量、射线的几何基础 | 作者在线教材；原文标注 CC BY-NC-ND 4.0，本次仅引用链接并独立解释，不搬运原文或图片 |

| [Microsoft · Graphics pipeline](https://learn.microsoft.com/en-us/windows/win32/direct3d11/overviews-direct3d-11-graphics-pipeline) 与 [Rasterizer stage](https://learn.microsoft.com/en-us/windows/win32/direct3d11/d3d10-graphics-programming-guide-rasterizer-stage) | 顶点、齐次裁剪、光栅、像素与输出阶段的职责；2026-10-21 补核对管线动画。教程严格区分 clip 坐标除以 w、NDC 与屏幕坐标 | Direct3D 11 官方说明，仅作为概念核对；不表示采纳 D3D11。文档许可按原站与其仓库许可，本次只链接 |

| [PBRT 4 · Sampling and Reconstruction](https://pbr-book.org/4ed/Sampling_and_Reconstruction) | 连续图像与离散采样、积分的联系 | 章节入口用于核对背景；实验是内部构造的覆盖率估计，非 PBRT 渲染器 |
| [Ray Tracing in One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html) | 作者在线版 v4.0.2（2025-04-25）；射线、相机、材质与路径追踪教学框架 | 文字 CC BY-NC-ND 4.0，代码 MIT；本次未复制代码与图片。既有 Engine 实现的依赖与许可仍由其原记录维护 |
| [Ray Tracing: The Next Week](https://raytracing.github.io/books/RayTracingTheNextWeek.html) | 2026-10-28 核对：`quad` 的平面求交与平面坐标判定一节——两步结构（先解 `t` 得平面交点，再读 `(α, β)` 判 `[0,1]`）、`w = n/(n·n)` 与 `α = w·(p×v)`、`β = w·(u×p)` 的叉积形式 | 与上一行同作者同系列在线教材；文字 CC BY-NC-ND 4.0，代码 MIT。本次只核对换算形式与结构，未复制代码与图片 |
| [W3C CSS Color 4 · sRGB](https://www.w3.org/TR/2026/CRD-css-color-4-20261020/#predefined-sRGB) | sRGB 与线性光 sRGB 的区别、传递函数 | 2026-10-20 候选推荐草案，并非正式最终标准；按 W3C 文档许可，仅链接和核对数值 |
