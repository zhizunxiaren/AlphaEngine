公式对照

项目式子
平面参数化P = Q + α·u + β·v
对偶基u* = (v.y, −v.x) / (u×v)　　v* = (−u.y, u.x) / (u×v)
读坐标α = (P−Q) · u*　　β = (P−Q) · v*
正交性u*·u = 1，u*·v = 0　　v*·v = 1，v*·u = 0
尺子长度|u*| = 1 / hu　　hu = |u×v| / |v|
叉积形式α = w · ((P−Q) × v)　　w = (u×v) / |u×v|²
直接点积 α′ = (p·u)/(u·u) 得到的是垂直投影，不是坐标。多出来的量恰好是 β·(u·v)/|u|² —— 也就是 β 沿着「斜」漏进了 α。

三个容易记错的点

常见误解实际情况
对偶基就是互相垂直它是互易关系：u* 垂直于 v（交叉），但 u* 与 u 的夹角一般不是 90°，且 u*·u = 1。
α 是距离或投影长度α 是格数，无量纲。同一格在不同基长度下对应的欧氏距离不同。
α 与 β 的叉积顺序可以对称写必须写成 p×v 与 u×p。若对称写成 v×p，得到的是 −α，因为叉积反交换。
