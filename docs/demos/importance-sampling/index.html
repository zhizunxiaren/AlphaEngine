重要采样与多重重要性采样（MIS）

蒙特卡洛渲染降噪的两级手段：先把样本放到值得放的地方（重要采样），再在没有任何单一分布能覆盖被积函数时，把多个分布缝成一个（MIS）。下面的每个演示都在实时跑真实的采样。中文文献里这一对概念也常写作「重要采样 / 多重重要采样」，MIS 是同一个东西。

一句话结论。整套东西只有一个量：单样本贡献 f/p。它越平稳，噪声越小。

① 重要采样：换 p。方差 = ∫f²/p − I²，所以最优 p ∝ |f|。不是「多采样」，是「换分布」。

② MIS：f 有两个因子（材质 fr、光照 Li），策略 A 只看得见前一个，策略 B 只看得见后一个。MIS 用一组和为 1 的权重把两个无偏估计缝成一个，方差接近两者中较好的那个。

③ 唯一真正困难的地方：两个 p 必须在同一个测度上。面积光源上的 1/A 是「每平方米」，BSDF 的 pdf 是「每球面度」，中间差一个 r²/cosθ。这步错了不是「噪点多一点」，是结果偏差。

1. 一个像素的亮度就是一个积分

1.1 为什么是积分

着色点朝相机发出的光，来自它上方半球里的每一个方向：每个方向有一束光 Li，被材质按方向"打折"（fr）后加进来，还要按入射倾角加权（cosθ）。方向是连续的，有无穷多个，所以求和变成积分：

Lo = ∫Ω fr(ωi,ωo) · Li(ωi) · cosθi dωi

被积函数记作 f(ω) = fr·Li·cosθ。这个积分没有解析解——Li 本身还依赖别的物体反射来的光，也是积分。所以只能抽样估计。

蒙特卡洛的做法只有一步：按某个概率分布 p 随机挑一个方向 ω，追踪这条光线，把它的贡献记作 f/p，再对很多次取平均。

I = ∫ f(x) dx ≈ (1/N) Σi f(xi) / p(xi)，　xi ~ p

1.2 为什么要除以 p

不是"补偿"这种模糊说法，它就是换元的定义。把积分从"对方向均匀地量"换成"按 p 的量法去量"，被积函数必须同时除以 p 的密度，否则总量会变：

∫ f(x) dx = ∫ [ f(x)/p(x) ] · p(x) dx = Ex~p[ f/p ]

这句话有两个直接后果，后面所有陷阱都从这里长出来：

① p 必须是你真正用来抽样的那个函数。写代码时 p 出现在分母里，容易误以为它只是"一个权重"。它不是——它是"这个样本被抽到的概率"。分母写错 = 每个样本被乘了一个错误的系数 = 结果系统性偏移，而且样本越多越稳定地偏移，看起来"很干净但颜色不对"。
② 只要 f≠0 的地方 p>0，估计就无偏。p 在哪里为 0，哪里就永远抽不到样本，那块贡献直接消失，这是"漏光/漏高光"。反过来 p>0 而 f=0 的地方无害，只是浪费样本。

1.3 噪声有多大：方差只由 f²/p 决定

方差衡量"单次估计围绕真值抖多厉害"：

Var[f/p] = E[(f/p)²] − I² = ∫ f²/p dx − I²

注意被积的是 f²/p，不是 f。这解释了两件事：

• p 该大在 f² 大的地方，也就是 f 大的地方——因为分子是平方，大值区域的双重惩罚更重。
• 对非负 f，令 p = f/∫f（即 p ∝ f），则 f/p ≡ ∫f 是常数，方差恰好为 0：每个样本都等于答案。这就是重要采样的理论天花板。

严格地说，使 ∫f²/p 最小的 p 是 p = |f|/∫|f|，此时最小方差 = (∫|f|)² − (∫f)²。f 不变号时这个下界是 0，全黑。

为什么不能靠堆样本？总方差按 σ²/N 下降，噪声按 1/√N 下降。降噪 2 倍要 4 倍样本，4 倍要 16 倍。而把 p 选对，σ 可以从 10 掉到 0.1，等于 10000 倍样本的效果。这就是重要采样存在的全部理由——它改的是系数，不是数量。

3.2 两个场景，各有一种策略是废的

场景一：粗糙表面 + 小而亮的灯。取一个半径 0.1 m 的球形灯，离着色点 2 m。它张开的立体角约 π·0.1²/2² = 0.0079 sr；整个半球是 2π = 6.28 sr。也就是说，随机撒方向只有 0.13% 能打中灯，大约八百个里才中一个。BRDF 采样在 6.28 sr 里均匀地乱撒，799 个样本贡献 0，第 800 个突然贡献巨大。平均值 = 一堆 0 加一个巨值，抖动极大。

光源采样直接把样本全放在灯面上，每个样本都有光。同一个场景，方差差几个数量级。

场景二：光滑表面 + 大面积光源。光源采样在灯面上均匀取点，但镜面 BRDF 只"接受"反射方向附近一个极窄的锥。大部分点被 fr 压成接近 0，样本全废在分母上。BRDF 采样把方向全塞进那个窄锥里，效果好。

真实场景往往两种情形同时存在（一盏大面光 + 一盏小射灯，或者同一材质在不同粗糙度区域表现不同），没有任何单一策略能赢两次。

3.3 关键一步：把两个 p 放到同一个测度上

这是 MIS 落地时最容易错、也几乎总是被教程跳过的一步。

BRDF 采样的 pdf 天然定义在立体角上，单位是 1/sr。光源采样如果是在灯面上均匀取点，pdf 定义在面积上，单位是 1/m²，值就是 1/A。这两个数不能直接比较，也不能直接放进同一个权重公式。

换算靠立体角的定义 dω = dA·cosθl / r²（θl 是灯面法线与光线的夹角，r 是到采样点的距离）：

pω(ω) = pA(y) · dA/dω = (1/A) · r² / cosθl

自检：一块 0.25 m² 的灯，距离 2 m 正对着看，Ω = A·cosθ/r² = 0.0625 sr，均匀分布的 pdf 应该是 1/0.0625 = 16 /sr。用公式：(1/0.25)·(2²/1) = 4·4 = 16 ✓。

怎么看演示 2。拖动距离和尺寸，观察 pA、dA/dω、pω 三个数怎么变。距离从 1 拉到 4，dA/dω 涨 16 倍——如果忘了这一步，你在权重里给光源策略的 pdf 就小了 16 倍，MIS 的份额分配完全错位。

A = L² = - m² 1/A = - /m² dA/dω = d²/cosθ = - m²/sr pω = - /sr 近似占半球 -
图中把光源当作距 d、正对视线的一小块，dA/dω = d²/cosθ 在该小块上取常值；真实实现里这一项要逐采样点计算。右侧百分比是 A·cosθ/d² ÷ 2π 的近似值，只用来建立"灯在方向空间里有多窄"的量感。
同类错误还有一处：环境贴图。环境贴图的采样分布通常定义在 (θ,φ) 或 (u,v) 上，映射到方向时 dω = sinθ dθ dφ，所以 pdf 必须乘上 sinθ。漏掉它的典型症状不是噪点，而是天顶/天底出现异常亮斑或暗带——因为极点附近的 sinθ 趋近 0，权重被系统性放大。

4. 为什么不能把两种采样直接加起来

假设策略 A 的估计 Ã 和策略 B 的估计 B̃ 都是 I 的无偏估计。那把两者的样本都算进去，加起来不就"用了双倍信息"？

不是。E[Ã + B̃] = I + I = 2I。两张正确的照片叠在一起，不是更清楚的照片，是曝光翻倍。

要加起来，就必须在每一个方向上把份额切开，使得任何位置 x 上两条路径分到的份额之和恰好是 1：

wA(x) + wB(x) = 1　⟹　E[Σ wi·f/pi] = ∫(wA+wB)·f dx = I

这就是 MIS 的全部内容：一个随 x 变化的划分（partition of unity）。剩下的问题只有一个——这个 w 该怎么分。

5. 多重重要性采样（MIS）

5.1 估计量

用 ni 个样本跑策略 i，xij 是策略 i 的第 j 个样本：

F = Σi (1/ni) Σj wi(xij) · f(xij) / pi(xij)，　Σi wi(x) ≡ 1

5.2 无偏的两个前提

① 权重在每一点和为 1，且 wi 只依赖 x、不依赖这个样本的取值（不能"看贡献大小再决定权重"，那就变成事后挑选，会引入偏差）。
② pi 必须是策略 i 真实的采样密度，且落在同一测度上。这一条比第一条更容易破，破了就是偏差，不是噪声。

5.3 平衡启发式：按"样本的来源概率"分账

把两个策略合成一个混合分布：pmix(x) = Σ nkpk(x) / Σnk。现在抽到一个位于 x 的样本，问它是策略 A 产出的概率——贝叶斯一步就得到：

P(A | x) = nApA(x) / (nApA(x) + nBpB(x))

平衡启发式就是取 wA = P(A|x)。它做的事非常朴素：样本在某个位置，"谁更可能生成它"，谁就拿走那里的权重。于是——

• 某个方向上策略 A 的 p 极小而 B 的 p 很大：这个样本几乎肯定是 B 生的，A 那点权重（比如 1.7%）就把 A 的稀有巨值 f/pA 压回去了。
• 反过来，B 在 A 的主场也是同样的下场。

在演示 2 的场景里，宽峰中心 x=0.72 处 pA = 0.08、pB = 4.67，wA ≈ 1.7%；窄峰中心 x=0.25 处 pA = 12.32、pB = 0.08，wA ≈ 99.3%。A 在宽峰处偶尔抽到的那个 f/pA ≈ 10.25 的"萤火虫"，乘上 1.7% 只剩约 0.17，被压平了。

注意这不是"整幅图选一种策略"，而是每个样本、每个方向单独加权。这也是它比"手动调一个混合系数"强的地方：混合系数是全局的一个数，MIS 的权重是每个方向上的一个函数。

5.4 幂启发式

wi = (nipi)β / Σk (nkpk)β，常用 β = 2

β=1 就是平衡启发式。β 越大，分账越"尖"：p 稍小的策略被压得越狠。好处是萤火虫被压得更低，坏处是在两个策略都不可靠的区域更依赖单一策略。实践上 β=2 的方差通常比平衡启发式低，所以工业渲染器多用它；平衡启发式的好处是 Veach 给出了它相对最优组合的方差上界，行为可预测。

多策略时，分母是所有策略之和（Σk 遍历全部），不是两两配对——三个策略两两配对会出现权重和不为 1。

6. 实战场：NEE + BRDF 的完整结构

这是路径追踪里 MIS 真正出现的地方。每个着色点做两件事，然后把两者加权合并：

// 策略 A：光源采样（Next Event Estimation）
y      = sample_point_on_light()           // 灯面上均匀取点
wi     = normalize(y - x)
pA     = p_pick_light * (1/A) * r² / |cosθ_y|   // ← 面积 → 立体角，关键一行
Li     = shadow_ray_blocked(x, y) ? 0 : Le(y)
fA     = brdf(x, wi) * |cosθ_x| * Li
wA     = pA / (pA + p_bsdf(wi))            // p_bsdf 在"同一个方向"上求值

// 策略 B：BRDF 采样
wi2    = sample_bsdf(x)
pB     = p_bsdf(wi2)
Li2    = trace(x, wi2)
fB     = brdf(x, wi2) * |cosθ_x| * Li2
pA2    = pdf_of_light_sampling(wi2)        // ← 需要反问：这个方向打得到灯吗？
wB     = pB / (pB + pA2)

contribution = wA * fA / pA + wB * fB / pB

三个容易漏的点，都在上面标了：

① pA 里的 r²/cosθ：见 §3.3。漏了它，MIS 就不是无偏的了（不是"效果差一点"）。
② wA 要算 pbsdf(wi)：BRDF 的 pdf 是解析的，给定方向就能算，代价低。必须算，否则 wA 就退化成 1，等于两个估计直接相加。
③ wB 要算 pA(wi2)：BSDF 采出来的方向能不能打到灯，需要一次求交才知道。打不到 → pA=0 → wB=1，可以跳过。这一步如果图省事跳过，等于 wB 恒为 1 —— 双倍亮度。

多光源：先按概率选一盏灯，ppick 必须进 pdf（按功率加权时 ppick = 功率占比）。漏了它，权重会偏向大功率灯。
阴影：被挡住时 Li=0，贡献为 0，但权重照算——因为权重只依赖 pdf，不依赖可见性。这是正确的，不要"优化"成可见性为 0 时把权重也让给另一个策略。

7. MIS 解决不了什么

情形为什么不行实际做法
硬阴影边缘可见性在方向上跳变，两个 p 都是光滑的，f 是阶跃的。MIS 只在两个分布之间分配份额，改不了 f 的不连续提高 SPP；屏幕空间/时域降噪；软光源
焦散（SDS 路径）镜面-漫反射-镜面，两端都不可采样，中间那一跳两个策略都到不了光子映射、双向路径追踪（BDPT）
极窄高光 + 极小灯两个 p 各自都对不准交集，份额怎么分都覆盖不全加第三策略、解析近似、专门的球形灯采样
降噪本身MIS 降低的是方差，不是把它变 0低差异序列（Sobol）、时域累积、降噪器
